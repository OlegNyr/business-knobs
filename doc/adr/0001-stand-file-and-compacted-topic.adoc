= ADR-0001: Параметры доставляются файлом стенда и компактным топиком
:revdate: 2026-10-17
:status: accepted

*Статус:* accepted (2026-10-17) ·
*Контракт:* `doc/contract/stand-file.adoc`

== Контекст

Сервису нужны настройки поведения — таймауты, пороги, признаки, тексты, — которые администратор
правит без выкатки, а значение зависит от контекста: ЦОД пода, арендатора, сегмента клиента и
т. п. Значения любого скалярного типа и списки. Правка должна доходить до каждого пода быстро,
под должен подниматься и работать, когда админка недоступна.

Выдача по HTTP со сверкой ревизий доводит правку до подов за минуты и меняет весь набор одной
ревизией; готовый провайдер флагов (например, flagd) даёт вторую правду о значениях рядом с
админкой.

== Решение

*Параметры живут в файле стенда в сборке сервиса и в админке; правка админки доезжает до
каждого пода записью компактного топика с версией на параметр.*

. Исходный файл — YAML разработчика. Сборка генерирует из него JSON на каждый стенд
  (`business-knobs-maven-plugin`).
. Версия — на параметр: время правки в миллисекундах, не меньше прежней плюс один.
. Каждый под читает топик сам, применяет запись с версией больше своей условной записью в
  реплику своей базы и держит снимок в памяти. Повторная доставка и переопубликация безвредны —
  решает версия.
. Значение выбирается правилом с самым точным подошедшим путём (ADR-0004).
. Брокер, клиент брокера и база реплики — на стороне сервиса: библиотека даёт SPI
  (`ParameterRecordApplier`, `ParameterReplica`), а не адаптеры.

== Последствия

*Хорошее.*

* Правка доезжает до пода за время доставки сообщения.
* Под поднимается без админки: файл стенда и реплика.
* Один формат на все сервисы.

*Плохое.*

* Атомарности между параметрами нет: правку двух ключей поды мгновение видят в разных версиях.
* Админка — отдельная система: загрузка каталога, редактор, публикация.

== Отвергнутые альтернативы

* *Выдача по HTTP вместе с топиком.* Два пути доставки пришлось бы держать согласованными;
  компактный топик уже полный источник состояния.
* *Готовый провайдер OpenFeature как источник.* Вторая правда о значениях рядом с админкой.
  OpenFeature при этом поддержан как API чтения (`Parameters#client()`).
